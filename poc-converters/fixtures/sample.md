# Panduan Penggunaan Konverter Desktop

Aplikasi **Konverter Desktop** adalah solusi *offline-first* modern untuk konversi berbagai format dokumen dan media.

## Fitur Utama
1. **PDF Tools**: Merge, Split, Compress, Protect, Unlock, Watermark, Rotate
2. **Document Converters**: Word, Excel, PowerPoint, HTML, Markdown
3. **Image Tools**: Compress, Convert, Resize

### Contoh Sintaks Kode
```rust
fn konversi_dokumen() {
    println!("Konversi 100% lokal dan aman.");
}
```

### Tabel Status Modul
| No | Modul | Format Target | Status |
|:---:|:---|:---|:---:|
| 1 | HTML to PDF | PDF | Selesai |
| 2 | Markdown to PDF | PDF | Fase 12 |

> Catatan: Semua proses berlangsung di mesin lokal pengguna tanpa transfer data keluar.
